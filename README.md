# 🖼️ NFTVerse — Card, CardList e Header

Projeto de estudo baseado no desafio [NFT preview card component](https://www.frontendmentor.io/challenges/nft-preview-card-component-SbdUL_w0U) do Frontend Mentor, evoluído para uma lista de cards com header.

🔗 **Acesse:** https://SEU-USUARIO.github.io/nft-cardlist/

## 🛠️ Tecnologias
- HTML5 semântico
- CSS3 (Grid, Flexbox, variáveis CSS, media queries)
- JavaScript (renderização dos cards)
- [Animate.css](https://animate.style/) — animações de entrada 
- [Leonardo.ai](https://app.leonardo.ai/) — imagens dos NFTs e logo 
- GitHub + GitHub Pages

## ✨ Funcionalidades
- Layout responsivo (mobile e desktop)
- Hover no card (elevação) e na imagem (overlay + ícone) 
- Animação de entrada escalonada (`fadeInUp`) 
- Header com menu hambúrguer no mobile
